# Data and art

- Opening names and PGN lines: [Lichess chess-openings](https://github.com/lichess-org/chess-openings), CC0. Imported 3,815 variations across 149 opening families on 2026-09-23.
- Piece artwork: [Ka-hu's Kaneo set](https://github.com/Kadagaden/chess-pieces), CC BY 4.0. The Kaneo set is inspired by Chess.com's Neo design; these are Kaneo's own SVGs.

- Opening order: a curated, approximate order of common systems, with remaining families alphabetical. The Lichess chess-openings TSV does not provide play counts; this is not a measured ranking. Pinned openings are stored locally in the browser.
- Engine analysis and evaluation: [Chess API](https://chess-api.com/) Stockfish endpoint. The bar shows the last received evaluation (white-positive) without an extra API request.
- Move, capture, check and checkmate sounds are generated locally with Web Audio; no third-party audio files are used.
